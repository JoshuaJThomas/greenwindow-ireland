# GreenWindow Ireland 🍃

Cleanest 3-hour window on the Irish grid, next 48 hours. Live EirGrid
data, a 1.6M-parameter distilled forecasting model on CPU, and the
scheduler from the accompanying MSc AI project report (National College
of Ireland).

Runs on Streamlit Community Cloud. To run locally:

    pip install -r requirements.txt
    streamlit run app.py
